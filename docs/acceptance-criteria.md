## 权限与聊天（M1–M2）

- 当前演示员工只能看到被分配且属于相应部门的项目。
- 管理员可创建演示员工、项目和成员分配。
- 项目可包含多个独立会话；会话可创建、重命名、浏览历史。
- 消息和上下文在刷新/重启后保留，归属字段完整。
- 追问继承结构化范围，关键决策重新调用 Tool。

## 销售导入（M3）

- 接受不超过 10 MB 的 CSV/XLSX，拒绝其他格式和超限文件。
- 相同 SHA-256 文件不会被重复导入。
- 映射、日期、数字、金额、必填项和重复行校验可复现。
- 确认前不写销售事实；确认写入失败时完整回滚。
- 报告包含总数、成功/失败数，错误行可导出。

## Agent 与选品（M4–M5）

- 六个 Tool 都有 Pydantic 输入输出、参数验证和调用日志。
- 模型不能访问任意 SQL/Python/Shell 或数据库连接。
- Mock 模式无 Key 可演示；真实 Provider 缺 Key 时给出安全错误。
- 指标由共享代码计算，固定样例的趋势、毛利、退款率和覆盖天数有断言。
- 补货数量由确定性规则生成，输出范围、指标、建议、风险和依据。
- 所有采购建议明确需要人工确认，系统不执行采购。

## 图片编辑（M6）

- 原图永不覆盖，每个结果形成带父级关系的版本。
- 保存提示词、Provider、模型、状态、错误和时间。
- 消息可引用原图/历史版本，版本可以继续编辑和下载。
- Provider 失败保留请求并支持重试，Mock 模式可完整演示。
